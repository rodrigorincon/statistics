# TESTE A/B

Como posso usar teste A/B para diversas finalidades posso usar diferentes testes para cada finalidade.

- Conversões (Cliques, Compras, Cadastros): teste Z (medir proporção) ou Qui-Quadrado (valores absolutos)
- Tempo no site / Ticket médio (valores contínuos): teste T ou Mann-Whitney (caso não siga as regras)
- Campanha de marketing (Público mais atingido por uma campanha): Anova de 1 via ou Kruskal-Wallis
