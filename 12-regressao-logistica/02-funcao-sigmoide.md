# FUNÇÃO SIGMOIDE

A função sigmoide transforma as entradas X (que variam de -infinito a +infinito) para uma saída entre 0 e 1. Assim podemos medir a probabilidade de cada categoria de Y. 

Isso é possível fazendo o log da chance (probabilidade da categoria dividido por todo o resto). Com isso chegamos a equação para encontrar as probabilidades de cada categoria.

$$p(y_i) = \frac{1}{1 + e^{-y_i}}$$

Aonde $y_i$ é uma categoria da variável Y.
